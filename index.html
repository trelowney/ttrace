ttrace APT repository

Packages of ttrace for Debian, Ubuntu and their relatives (amd64 and arm64). Install:

sudo curl -fsSL -o /etc/apt/keyrings/ttrace.asc https://trelowney.github.io/ttrace/ttrace.asc
echo "deb [signed-by=/etc/apt/keyrings/ttrace.asc] https://trelowney.github.io/ttrace stable main" | sudo tee /etc/apt/sources.list.d/ttrace.list
sudo apt update
sudo apt install ttrace

On older systems without /etc/apt/keyrings, create it first: sudo mkdir -p /etc/apt/keyrings.

The package lets ttrace send probes without sudo. Updates come with the usual sudo apt upgrade.
